# Plant_Species_Image_Classification
Laboratory Work 2-A | Image Classification Using Teachable Machine

## A. Project Overview
**Project Description:** 
This project is an image classification machine learning model built using Google Teachable Machine. It is designed to recognize and classify 20 distinct but visually related plant species based on leaf shape, color, and variegation patterns. 

**Purpose:**
The primary purpose of this model is to accurately identify houseplant species from user-uploaded images or live webcam feeds. This serves as a demonstration of computer vision and transfer learning techniques applied to botanical classification.
